For round-duration outlier detection, we identified unusually long rounds using a median absolute deviation (MAD) approach applied to `round_dur_s`. Outlier statistics were computed within the preferred grouping level of `main_RR × sessionID`, and rounds were flagged when their round duration exceeded 3.0 robust MAD-based units above the group median. This approach was selected because it targets unusually slow rounds while remaining less sensitive to extreme values than standard deviation-based thresholds.

Round-duration outlier detection was performed on `round_dur_s` using robust group-based summary statistics. For each grouping level considered, the group median was used as the measure of central tendency. We then calculated the median absolute deviation (MAD), defined as the median of the absolute deviations from the group median, and converted it to a robust scale estimate using the constant 1.4826. For each round, a robust standardized score was calculated as `(round_dur_s - group median) / robust scale`, and rounds were flagged as outliers when this value exceeded a prespecified threshold of 3.0. Because the scientific goal was to identify unusually long rounds, this was implemented as an upper-tail rule only; unusually short rounds were not excluded.

As a secondary reference method, we also computed interquartile range (IQR)-based statistics. For the IQR method, the 25th percentile (Q1), median, 75th percentile (Q3), and IQR (`Q3 - Q1`) were calculated for each group, and an upper outlier fence was defined as `Q3 + 1.5 × IQR`. Rounds above this upper fence were classified as IQR-based outliers. These values were retained for transparency and comparison, but they were not used as the primary exclusion rule.

The MAD-based method was preferred over IQR for this analysis for several reasons. First, MAD provides a continuous per-round deviation score, which makes it easier to quantify how unusual a given round is relative to the typical rounds in its group. Second, MAD is highly robust to extreme values, which is important when the primary concern is occasional abnormally long rounds that could otherwise distort the estimated spread of the data. Third, the MAD framework is well suited to an “annotate first, filter later” workflow, because it yields both interpretable summary statistics and an explicit outlier score for each round. In contrast, the IQR approach is useful as a conventional reference method but is more limited as a primary tool because it is based on quartile fences rather than a graded deviation metric.

For the main analysis, the preferred grouping level was `main_RR × sessionID`, and the preferred method was MAD. This grouping structure was chosen to keep main and RR cohorts separate while also allowing round duration to be evaluated relative to a participant’s local session-specific baseline. The final preferred outlier flag therefore identified rounds with unusually long durations relative to the median round duration of their `main_RR × sessionID` group, using a threshold of 3.0 robust MAD-based units.
