# Path-choice multi-panel plotting suite

This revision preserves the original participant/session faceted plots and adds the same representative/cohort comparison workflow used in the other plotting suites.

## New comparison figures

For each selected representative pair, the suite can generate both violin and path-proportion versions of:

### 3-panel representative comparison

1. All participants
2. Main representative
3. RR representative

### 2×2 cohort comparison

Top row:
1. Main cohort
2. RR cohort

Bottom row:
3. Main representative
4. RR representative

Cohort membership defaults to `main_RR`, with values `main` and `RR`.

## Representative roles

The wrapper reads a roles table containing, by default:

- `role`
- `main_seed42`
- `RR_seed50`

The path-specific role defaults to `pathChoice`. If your roles CSV uses a different row name, pass it explicitly with `--representative-role`.

The fixed general representative role defaults to `generalRepresentative`.

## Example

```bash
python pathChoiceWrapper.py \
  --input AN_PinDropsKnottedFiltered_noABCD_all.csv \
  --summary participantSummaryData_AN.csv \
  --roles randomizedRoles_42.csv \
  --out-dir path_choice_results \
  --formats png,pdf \
  --representative-role pathChoice \
  --representative-mode both \
  --figure-mode both
```

## Comparison controls

```bash
--figure-mode both
--figure-mode representatives
--figure-mode cohorts

--representative-mode both
--representative-mode path-specific
--representative-mode general

--cohort-column main_RR
--main-cohort-value main
--rr-cohort-value RR
```

The original participant/session plots are still generated by default. To suppress them:

```bash
--no-individual-plots
```

To skip all proportion plots and generate violins only:

```bash
--no-proportion-plot
```

## Outputs

The original outputs remain:

- `path_choice_faceted_violins.*`
- `path_choice_faceted_proportions.*`
- `path_choice_code_lookup.csv`
- `path_choice_round_level_merged.csv`
- `path_choice_counts_proportions.csv`
- `path_choice_participant_summary.csv`

New outputs follow this pattern:

- `path_choice_representatives__path_specific__violins.*`
- `path_choice_representatives__path_specific__proportions.*`
- `path_choice_cohorts__path_specific__violins.*`
- `path_choice_cohorts__path_specific__proportions.*`
- and equivalent `__general__` files.

`manifest.json` records the selected representatives, cohort counts, plot modes, and generated files.

## Data behavior

Path codes 1–6 remain the plotted categories. Existing round-level validation is preserved. The `main_RR` cohort column may come from either the pin-drop input or the participant summary. If it exists in both, the suite checks that the values agree before merging.
